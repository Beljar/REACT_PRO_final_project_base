### Структура папок

Приложение реализовано согласно архитектуре FSD, структура папок поделена на слои:

![folder-structure](screenshots\folder-structure\folder-structure.png)

App: точка входа, провайдеты, рутинг
Pages: страницы приложения
Widgets: комбинированные элементы интерфейса, требующие сочетания различного функционала
Features: бизнес-логика над конкретными сущностями, одна фича = одно действие над одной сущностью
Entities: бизнес сущности, их специфический UI, работа с api и store
Shared: общий функционал, не относящийся к бизнес логике (презентационное UI, конфиги, общие утилиты)
